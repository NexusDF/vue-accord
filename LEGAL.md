# Legal / Правовая информация

**Vue Accord** — клиентская библиотека аккордов и текстов для личного использования в браузере. Это не юридическая консультация.

## Copyrighted seed sheets / Демо-разборы

Файл `src/data/seedSongs.js` содержит тексты и chord sheets известных песен (Кино, Oasis, Radiohead, The Beatles и др.). Они **не принадлежат** авторам приложения и, скорее всего, являются **нелицензированным охраняемым материалом**.

- Для **локальной разработки / личного офлайн-использования** риск ниже, но права правообладателей всё равно действуют.
- **Публикация на GitHub Pages (или любом публичном хостинге)** = распространение копий текстов/аккордов третьим лицам → **высокий риск нарушения авторских прав** (DMCA / претензии).

Рекомендации перед публичным деплоем:

1. Собрать без сидов: `VITE_INCLUDE_SEEDS=false` (см. `.env.example`), **или**
2. Заменить сиды на явно оригинальные / CC0 примеры, **или**
3. Оставлять только пользовательские листы в `localStorage`.

Флаг `VITE_INCLUDE_SEEDS` по умолчанию `true` (локальный `npm run dev`). Workflow GitHub Pages собирает с `VITE_INCLUDE_SEEDS=false`. Оригинальные учебные листы — `src/data/practiceSongs.js`. **Важно:** сам файл `seedSongs.js` в публичном репозитории GitHub всё равно является распространением контента.

## Third-party APIs / Сторонние API

| API | Назначение | Заметки |
|-----|------------|---------|
| **Songsterr** (`src/api/songsterr.js`) | Поиск метаданных, ссылки на страницы аккордов/табов | В dev — прокси Vite (`/api/songsterr`) из‑за CORS. **GitHub Pages не может проксировать**. Без `VITE_SONGSTERR_API_BASE` в production клиент Songsterr не вызывается. Неофициальные JSON-эндпоинты; ToS Songsterr запрещают обход Plus и вмешательство в плеер — приложение не скачивает нотацию/GP и не скрапит HTML. |
| **LRCLIB** (`src/api/lrclib.js`) | Публичный lyrics API (CORS, без ключа) | Соблюдайте [документацию](https://lrclib.net/docs): идентифицирующий `User-Agent`. Разрешение LRCLIB на использование API **не лицензирует** тексты песен от правообладателей. Кэш в `localStorage` — только на устройстве пользователя. |

Ключи API в репозитории не используются.

## App code / Код приложения

Исходный код UI (Vue, утилиты аккордов, диаграммы) — отдельно от встроенных текстов песен. Авторство seed-контента приложением **не заявляется**.

## GitHub Pages

Статический хостинг: нет серверного прокси, нет секретов на сервере. Любой контент, попавший в `dist/` (включая seed sheets при `VITE_INCLUDE_SEEDS=true`), становится публично доступным.
